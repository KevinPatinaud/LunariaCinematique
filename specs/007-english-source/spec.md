# Code source de Lunaria en anglais

## Exigences

- **FR-001** Les noms techniques, commentaires et diagnostics destinés au développement sont en anglais.
- **FR-002** Les dialogues, libellés, textes narratifs et messages présentés aux utilisateurs restent en français.
- **FR-003** Le renommage du module d’animation partagé se répercute de la source Studio à ses copies Godot. Les identifiants de catalogue et les références de médias restent utilisables avec les projets d’auteur existants.

## Scénarios d’acceptation

- **SC-001** Les outils chargent le module et les suites de jeu retrouvent les scénarios renommés.
- **SC-002** Les tests de contenu et d’interface chargent les catalogues et les libellés français.
