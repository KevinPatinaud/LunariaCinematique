# Plan

Réutiliser les entrées du catalogue de présentation et les placements des objets de décoration. Les entrées dédiées référencent une ou deux images et les paramètres des préréglages. Le placement conserve le lien vers l’entrée, le délai, la vitesse et le mode de lecture. Le schéma et le lecteur GDScript sont maintenus dans le Studio, puis synchronisés avec le jeu.

Le même calcul échantillonne chaque image à partir du temps local. Les médias suivent le préchargement de la cinématique et le pipeline de publication existants. L’édition et le placement passent par la session du projet pour conserver l’annulation.
