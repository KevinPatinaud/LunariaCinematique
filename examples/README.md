# Exemples historiques

Ces projets JSON décrivent d’anciennes versions du Studio et du jeu. Ils sont
conservés comme archives de conception ; leurs espèces, objectifs et liens vers
des films séparés ne sont pas tous compatibles avec le contrat actuel.

Pour travailler sur Lunaria, ouvrir le projet complet :
`C:/dev/Lunaria/HISTOIRE DE LUNARIA/Cinematiques studio/lunaria.game.json`.
Pour expérimenter, utiliser **Fichier → Nouveau projet** et créer les
cinématiques dans ce projet. La démonstration de composition intégrée au Studio
reste disponible depuis **Essayer l’exemple**.
